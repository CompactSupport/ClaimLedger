# Maintenance

CompactSupport is the only maintainer with commit access. There is no bus-factor measurement beyond that fact, and no maintained-hours figure is recorded.

Release work is the changelog, the offline tests, and the GitHub Actions workflow. PyPI Trusted Publishing is prepared as a manual workflow and has not been used.

Private grant drafts, if any are written later, stay outside the Git repository in an untracked directory such as `private/grants/`.
